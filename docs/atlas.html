为什么需要本地接入：很多平台（包括 Instabox）只发布 HTTP 端口，不提供公网裸 TCP。槽位 SOCKS5 只能监听在容器内网，于是把链路倒过来——本机开 SOCKS5，公网只走 HTTPS。
